# Smart Tab Organizer

Organize cluttered Chrome tabs into color-coded tab groups, sleep inactive tabs to save RAM, and save & restore workspaces — 100% locally in your browser.

## Features

- **Smart Category Grouping:** Automatically organizes open tabs into color-coded Chrome tab groups.
- **Auto-Group as You Browse:** Newly opened tabs join the right group automatically.
- **Sleep Tabs (RAM Saver):** Put inactive tabs to sleep in one click or automatically after 30 minutes.
- **Saved Workspaces:** Save entire windows with colored tab groups and restore them in one click.
- **Duplicate Cleaner:** Detect and close exact duplicate URLs safely.
- **10 Languages:** English, Turkish, Spanish, Chinese (Simplified), Hindi, Arabic, Portuguese (Brazil), French, German, and Japanese.
